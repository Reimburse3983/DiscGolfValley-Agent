## About
This is my final project for my Machine Learning class. I am creating a Reinforcement Learning Model to play the game Disc Golf Valley on Steam. 

## Preconditions:
In order for the project to run successfully, the game Disc Golf Valley must be already open and have a course selected. The main function is going to automate this functionality; however, that section is still in progress. To get the model to learn, simply select the course and then run the Gameplay Loop.py file.
